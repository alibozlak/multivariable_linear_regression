## The Model

`f(x) = a0*x0 + a1*x1 + ... + a(n-1)*x(n-1) + b`

The data set is generated by Gemini : the square meters and the room count of a flat
are the inputs, its monthly rental price is the expected output. The cost function `J`
is the mean of the squared errors, and the `a` coefficients and `b` are fitted with
plain gradient descent, **without any feature scaling**.

## Run

```sh
cargo run --release
```

One line is printed per gradient descent step and the training loop runs 1,000,000
steps, so writing the output to a file is usually the more comfortable option :

```sh
cargo run --release > train.log
```

Because the features are not scaled, the learning rate has to stay very small
(`0.00003`) to keep the descent stable, and the cost therefore goes down slowly.
